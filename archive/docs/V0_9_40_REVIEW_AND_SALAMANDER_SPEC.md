## 1. `v0.9.40` 업데이트 종합 평가 기록

## 2. 도룡뇽(Salamander) 아이콘 · 앱 내 게이지 · 4단계 캐릭터 검토 기록

### 2.1. 명칭 및 시각 구조
- **공식 명칭**: 인위적인 조어 대신 담백한 보통명사 **도룡뇽 / Salamander** 그대로 유지 (`도룡뇽 1~4단계` / `Salamander stage 1~4`).
- **앱 아이콘 ↔ 앱 내 게이지(`CoreIndexGauge.kt`) 일원화**:
  - `drawSalamanderGauge`와 `rememberGaugeHeads`를 통해 대시보드 메인 게이지도 앱 아이콘과 동일하게 **도룡뇽 몸통이 점수 비율만큼 빨간 링을 덮고 머리가 끝에서 빨간 링을 먹는 형태**로 통일됨.
  - 점수 숫자와 단계 텍스트(`안정·보통·주의·휴식 필요`)를 게이지 원 아래(`Column`)로 분리 배치해 그래픽과 글자의 겹침을 원천 해소함.
- **1~4단계 성장 캐릭터(`SalamanderStageIcon.kt`, `ic_salamander_stage1~4.xml`)**:
  - **1단계(유생: 큰 꽃잎 아가미·꼬리 지느러미) → 2단계(다리가 남) → 3단계(몸이 길어짐) → 4단계(다 자라 꼬리로 원을 감음)**으로 구성되어, 4단계 완전체가 대시보드 메인 코어 게이지의 원형 도룡뇽으로 이어지는 서사를 완성함.

### 2.2. 미세 점검 포인트 3가지
1. **`CoreIndexGauge.kt` 호출부 높이 제약 확인**: `CoreIndexGauge`가 `Column(Canvas + 점수 + 단계)` 구조이므로 호출부에서 고정 `height`/`size` Modifier를 주지 않고 `iconSize` 파라미터로만 크기를 제어하는지 확인.
2. **`celebrate = true` 초기 프레임(`0f`) 확인**: 단계 상승 애니메이션 시작점(`animatedScore = 0f`)에서 도룡뇽 머리 위치가 12시 전원 막대와 어색하게 겹치지 않는지 시각 확인.
3. **`StreakRewardRow.kt` 영어 내 기록 단위**: `Fewest unlocks $it`의 단위 표기 일관성 점검 (아래 3절의 횟수 단위 개편안과 연동).

## 3. 잠금 해제 / 앱을 연 횟수 단위: `x` 대체 방안 검토

### 3.1. 현재 `x` 표기(`48x`)의 문제점
- 한국어 사용자에게는 `'48배(배수/배속)'` 또는 닫기(`×`) 기호로 읽힐 수 있고, 영어권에서도 라벨이 `Unlocks`일 때 값에 `48x`를 붙이면 `'48배 증폭'`처럼 보여 일반 소비자 앱보다는 개발자 도구처럼 느껴질 수 있습니다.

### 3.2. 영어·한국어 횟수 표기 대안 비교

| 대안 | 숫자 칸 표기 (라벨이 이미 있을 때) | 문장·혼합 줄 표기 | 일평균 표기 | 장점 및 단점 (Apple / Google 비교) |
| :--- | :--- | :--- | :--- | :--- |
| **안 1 (최고 추천)**<br>**라벨 칸은 '순수 숫자',<br>문장은 `회` / `times·opens`** | • 한/영 공통: **`48`**<br>*(단위 기호 생략)* | • 한: **`48회`**<br>• 영: **`48 times`**<br>*(또는 `48 opens` / `48 unlocks`)* | • 한: **`일 12회`**<br>• 영: **`12/day`** | • **Apple 스크린 타임·Android 디지털 웰빙·Oura의 실제 표준 방식**<br>• 카드 제목이 이미 `잠금 해제(Unlocks)`나 `실행 횟수(Opens)`이므로 숫자 칸에는 **`48`**만 적는 것이 가장 깔끔하고 오독 가능성 0%<br>• 숫자도 더 크게 보이고 `min`·`P`와도 헷갈리지 않음 |
| **안 2**<br>**행동 명사 복수형 단위**<br>(`opens` / `unlocks`) | • 한: **`48회`**<br>• 영: **`48 unlocks`** 또는 **`12 opens`** | • 한: **`48회`**<br>• 영: **`48 unlocks`** / **`12 opens`** | • 한: **`일 12회`**<br>• 영: **`12/day`** | • 영어에는 한국어 `'회'`에 대응하는 1~2글자 기호가 없으므로 미국 앱에서 가장 자연스럽게 쓰는 방식<br>• 단, 좁은 숫자 타일 안에서는 `unlocks`(7글자)가 길어 `0.65em` 축소 또는 줄바꿈 고려 필요 |
| **안 3**<br>**`times` 고정 표기** | • 한: **`48회`**<br>• 영: **`48 times`** | • 한: **`48회`**<br>• 영: **`48 times`** | • 한: **`일 12회`**<br>• 영: **`12/day`** | • 잠금 해제·앱 실행·짧은 확인 어디에나 공통으로 쓸 수 있는 가장 쉬운 영어 단어<br>• 숫자 칸에서는 `48` 뒤에 작은 글씨(`0.7em`)로 ` times`를 붙임 |

### 3.3. 권장 적용 기준 (가장 깔끔한 해결책)
1. **라벨이 이미 붙어 있는 숫자 칸** (대시보드 요약 2번째 칸 `잠금 해제 / Unlocks`, 주간 리포트의 `하루 잠금 해제 / Daily Unlocks` · `하루 짧은 확인 / Daily Quick Checks` 등):
   - 굳이 `x`를 붙이지 않고 **순수 숫자(`48`)**만 표시하거나, 한국어는 **`48회`** / 영어는 **순수 숫자(`48`)**로 표시합니다.
   - 전주 대비 증감 역시 `+5x` 대신 **`+5`** (또는 한국어 `+5회` / 영어 `+5`)로 표기하면 '5배'라는 오해가 완전히 사라집니다.
2. **일평균 앱 실행/잠금 해제 수 (`StatisticsExplorer.kt`)**:
   - 한국어: **`일 12회`** / 영어: **`12/day`** (슬래시 표기는 짧으면서도 영미권 사용자에게 100% 직관적입니다).
3. **문장 또는 한 줄 요약 (`StreakRewardRow.kt` 등)**:
   - 한국어: `잠금 해제 최소 12회` / 영어: `Fewest unlocks 12` (앞에 이미 `unlocks`가 있으므로 뒤에 단위를 안 붙여도 완전한 영어 구문이 됩니다!).
