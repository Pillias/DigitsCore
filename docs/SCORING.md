# 코어 지수 계산 방식

이 문서는 현재 main의 `RollingScoreCalculator`를 기준으로 합니다. 코어 지수는 의료·심리 진단 점수가 아니라 사용 흐름을 비교하기 위한 제품 내부 지표입니다.

## 기본 원칙

- 계산 창은 현지 시각의 날짜가 아니라 **현재 시점 직전 24시간**입니다.
- 점수는 자정에 초기화되지 않습니다.
- 화면 ON·잠금 해제 상태에서 전면에 표시된 앱만 계산합니다.
- 화면 OFF 백그라운드 재생은 제외합니다.
- 좋은 앱 사용은 보너스가 아니라 더 작은 부하로 처리합니다.
- 모든 사용 부하가 0 이상이므로 서로 다른 등급의 사용이 가감으로 상쇄되지 않습니다.
- 최종 범위는 1~100입니다.

## 1. 최근 24시간 누적 부하

각 세션의 사용 분에 앱 등급별 계수를 곱합니다.

| 단계 | 이름 | 분당 부하 |
|---:|---|---:|
| 1 | 성장 | 0.040 |
| 2 | 집중 지원 | 0.048 |
| 3 | 균형 | 0.060 |
| 4 | 절제 | 0.095 |
| 5 | 몰입 관리 | 0.120 |

4·5단계 앱을 00:00~05:00에 사용한 구간에는 1.25배를 적용합니다. 최근 24시간 언락이 20회를 넘으면 초과 1회당 0.12 부하를 더합니다.

```text
rollingLoad = Σ(사용 분 × 등급별 분당 부하 × 심야 계수)
            + max(언락 수 - 20, 0) × 0.12
```

## 2. 연속 사용 급성 부하와 회복

같은 앱 세션 사이 간격이 90초 이하면 하나의 연속 세션으로 봅니다. 가장 최근 세션이 90초 이내에 끝났으면 현재 사용 중인 흐름으로 취급합니다.

- 30분까지는 급성 부하가 없습니다.
- 30분을 넘긴 길이에 비선형 가속을 적용합니다.
- 단계별 급성 계수: 1·2단계 0, 3단계 0.20, 4단계 0.55, 5단계 1.00
- 사용을 멈추면 35분마다 절반으로 감소합니다.

```text
peakAcute = 34 × (max(연속 사용 분 - 30, 0) / 150)^1.3 × 단계 계수
acuteLoad = 사용 중이면 peakAcute
            쉬는 중이면 peakAcute × 0.5^(휴식 분 / 35)
```

수면이나 장시간 화면 OFF 자체로 점수를 추가하지는 않습니다. 다만 급성 부하가 사라지고 오래된 세션이 24시간 창 밖으로 이동하면서 점수가 회복됩니다.

## 3. 원점수

누적 부하와 급성 부하를 합쳐 포화 곡선으로 변환합니다.

```text
totalLoad = rollingLoad + acuteLoad
rawScore = 100 / (1 + (totalLoad / 45)^1.43)
```

이 곡선은 일반적인 사용을 60~90점대에 두고, 매우 높은 점수와 매우 낮은 점수가 쉽게 나오지 않도록 설계했습니다.

## 4. 50~90점 반응 확대

점수가 잘 변하지 않는 느낌을 줄이기 위해 50~90점에 단조 증가 S자 응답을 적용합니다. 50·70·90은 변하지 않으며 바깥 구간도 원점수를 그대로 사용합니다.

```text
x = (rawScore - 50) / 40
responsiveScore = 50 + 40 × [x + 0.8 × x × (1-x) × (2x-1)]
```

대표 변환은 다음과 같습니다.

| 원점수 | 표시 계산값 |
|---:|---:|
| 50 | 50 |
| 60 | 57 |
| 70 | 70 |
| 80 | 83 |
| 90 | 90 |

50 미만과 90 초과는 변환하지 않으므로 희소 구간의 성격은 유지됩니다.

## 5. 초기 보정

데이터가 없는 새 설치에서 극단 점수를 단정하지 않도록 80점에서 시작합니다. 누적 전면 사용 60분까지 실제 계산값의 비율을 선형으로 늘립니다.

```text
progress = min(누적 보정용 전면 사용 / 60분, 1)
score = 80 × (1-progress) + responsiveScore × progress
```

보정 중에도 점수는 표시되며 UI에서 보정 상태를 함께 안내합니다.

## 6. 등급

| 점수 | 등급 |
|---:|---|
| 90~100 | S |
| 80~89 | A |
| 70~79 | B |
| 60~69 | C |
| 40~59 | D |
| 1~39 | F |

## 기존 일일 점수와의 관계

`ScoreCalculator` 기반 기존 점수 계산은 저장 데이터와 설정 호환을 위해 내부적으로 유지하지만 사용자 화면에는 표시하지 않습니다. 메인 화면, 점수 상세, 상태바 알림과 위젯의 기준은 모두 최근 24시간 `RollingScoreCalculator`가 만든 코어 지수입니다. 두 엔진의 계수와 의미가 다르므로 기존 설정의 `+50%/-100%` 표현을 코어 지수의 직접 가감 비율로 해석하면 안 됩니다.

앱별 5단계 등급은 두 엔진에 반영되지만, 프리셋과 감점·회복·이월 같은 세부 사용자 계수는 현재 기존 일일 점수에만 적용됩니다. 최근 24시간 코어 지수의 계수는 실사용 분포를 검증하는 동안 코드의 고정값으로 관리합니다.

## 변경 시 검증 기준

- 빈 기록은 보정 상태 80점에서 시작해야 합니다.
- 3시간 연속 5단계 앱은 약 40점대가 되어야 합니다.
- 같은 사용 뒤 약 3시간 휴식하면 70점대로 회복해야 합니다.
- 1단계 앱도 100점 보너스를 만들지 않아야 합니다.
- 50·70·90 반응 경계는 고정되어야 합니다.
- 점수 함수는 부하가 커질수록 증가하지 않아야 합니다.

관련 테스트: `RollingScoreCalculatorTest`, `ScoreCalculatorTest`, `ScoreGradeTest`.
