# 누적 코어 지수 (모델 5 / 설정 버전 1)

계산: `CumulativeScoreEngine`, 이벤트 처리: `CumulativeTimeline`, 영속 저장: `CumulativeScoreStore`.
제품 내부 지표이며 의료적 평가나 실제 인구 평균이 아닙니다. [이전 모델 4](SCORING_LEGACY_V4.md)는 호환용입니다.

## 동작

- 신규 시작 75점, 표시 범위 1–99. 업데이트는 마지막 표시 점수를 유지합니다.
- 점수·사용 가속 잔여·회복 부담·처리 시점을 암호화 DB에 저장합니다. 자정/24시간/48시간 초기화는 없습니다.
- 24시간/일별/주별은 통계 조회 범위이며 점수 만료 기간이 아닙니다.
- 일반/관리 두 등급. 동영상·SNS·게임은 기본 관리 추천이며 교육·쇼핑·음악 등은 일반입니다. 사용 자체에 가점은 없습니다.
- PiP/분할 화면은 높은 등급을 한 번만 적용하고 화면 OFF 재생은 제외합니다.
- 1분 이하 확인은 열기 비용만 적용하고 휴식을 초기화하지 않습니다. 짧은 재진입을 묶어 누적 1분을 넘긴 뒤부터 면제를 해제합니다.
- 1분 초과 사용은 시작부터 반영하도록 약 2분 확정 지연을 둡니다.
- 추적 중지/관측 공백을 미사용으로 간주해 점수를 생성하지 않습니다.

## 계수와 튜닝

`CumulativeScoreConfig`에서 표시 앵커 `scoreAnchors`와 반응 속도 `responseAnchors`를 분리했습니다.
아래 값은 표시 점수가 아닌 내부 상태(signal)에 적용됩니다.

| 항목 | 값 |
|---|---:|
| 일반 / 관리 분당 기본 손실 | 0.04 / 0.07 |
| 열기 비용 | 0.1 |
| 가속 시작 / 단계 길이 | 30분 / 15분 |
| 일반 / 관리 단계당 추가 배율 | 0.06 / 0.12 |
| 활동 중 휴식의 부담 반감기 | 4.5시간 |
| 회복 배율 | 1.02 |

60분 사용 뒤 30분 쉬면 가속 잔여가 30분이 되어 두 단계 내려갑니다.
수면은 점수와 회복 부담을 동결하고 사용 가속 잔여만 줄입니다. 활동 중 휴식은 회복을 만들지만 이전 관리 사용의 부담이 이를 억제합니다.
낮은 영역의 감점과 높은 영역의 회복은 완화되며 최댓값은 99입니다.
배포 후 기존 설정 버전을 수정하지 않고 새 버전을 만들어 회귀 테스트합니다.

## 수면과 기상

최근 야간의 긴 비사용 간격으로 취침·기상 구간을 학습합니다. 표본이 부족하면 23–07시 보호 구간입니다.
아침 카드에서 활동 시작/아직 쉬는 중을 선택할 수 있고 매일 시간 입력은 필요하지 않습니다.
선택한 경우 하드웨어 걸음 센서의 아침 15분 내 50걸음을 보조 근거로 사용합니다. 위치·원시 센서 이력을 보관하지 않으며 걸음 부재를 수면 증거로 보지 않습니다.
권한/센서가 없어도 기본 측정은 동작합니다. 오판 보정은 미래 처리에만 적용하고 이미 받은 점수를 회수하지 않습니다.
00–06시 사용이 30분 이상 겹친 세션을 오전 10시 전에 마치면, 이후 첫 5시간은 늦은 취침의 보조 보호 구간으로 봅니다. 활동 시작 확인이나 걸음 근거가 있으면 이 보호를 해제합니다. 5시간이 지나도 학습한 수면 구간이 남아 있으면 계속 보호하며, 모든 사용자에게 매일 5시간을 일괄 차감하지는 않습니다. 보호 구간과 걸음 판단은 실제 Samsung 기기 검증이 필요합니다.

## 합성 일정 회귀 기준

75점 출발, 8시간 수면, 실제 사용 외 짧은 확인 최대 5회. 실제 사용자 평균이 아닙니다.

| 매일 반복 | 1일 끝 | 7일 끝 |
|---|---:|---:|
| 일반 30분 | 83.85 | 91.00 |
| 일반 1시간 | 82.36 | 89.39 |
| 일반 3시간 + 관리 1시간 분산 | 75.11 | 75.15 |
| 관리 4시간 연속 | 64.93 | 42.61 |
| 관리 6시간 연속 | 50.01 | 33.22 |
| 관리 10시간 연속 | 32.61 | 21.17 |

7일 종료와 90일 종료의 차이 2점 미만을 테스트합니다. 첫날 즉시 40점으로 만드는 것이 아니라 약 1주일의 반복 패턴이 중요합니다.

## 기록과 이전

DB 17→18은 기존 사용기록을 삭제하지 않습니다. 모델 버전을 점수 표본에 남기고 다른 모델의 차트 선을 구분합니다.
백업 v10에 누적 체크포인트를 포함하며 백업 후 오프라인 시간은 회복으로 계산하지 않습니다.
전체 기록 삭제 시 누적 상태도 삭제합니다. 예전 계수는 호환용이며 현재 UI는 일상 균형만 제공합니다.
