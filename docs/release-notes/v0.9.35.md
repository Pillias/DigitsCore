## DigitsCore v0.9.35

비공개 테스트용 업데이트입니다. 기존 기록과 설정은 그대로 이어집니다. (DB 19 → 20, 새 테이블 추가만)

### 새 기능
- **주간 리포트**: 매주 월요일 05:00 이후 지난주 코어 지수 마감 평균, 목표별 달성 일수, 화면 시간·잠금 해제·짧은 확인, 많이 늘거나 줄어든 앱, 한도 선택 기록을 알려 줍니다.
- **잠금 해제 후 처음 연 앱 / 알림이 부른 잠금 해제**: 잠금 해제 상세와 통계 앱 순위에서 무엇이 폰을 집게 하는지 보여 줍니다.
- **한도 도달 시 선택**: 관리할 앱 한도에 닿으면 알림에서 "15min 더" 또는 "오늘은 여기까지"를 고릅니다. 앱을 막지 않습니다.
- **관리 앱 전체 한도**: 목표 2를 앱 1개 대신 관리 앱 전체 합계로 정할 수 있습니다.
- **평일·주말 목표**: 평일과 주말 목표를 따로 저장합니다.
- **시간대 규칙**: 업무·수면 준비 시간대에 화면 신호등을 더 일찍 켭니다(최대 3개, 점수 계산은 그대로).
- **디지털 웰빙과 다른 이유**: 화면 시간 상세에서 OS 화면 시간과 차이 나는 항목(05:00 기준, 홈 화면 시간 등)을 보여 줍니다.
- **지난 기록 불러오기**: 처음 추적을 켤 때 기기에 남은 최근 기록(최대 7일)을 불러와 통계와 목표 추천에 씁니다.
- **위젯**: 가로 4칸 이상 위젯에 오늘의 목표 3가지를 표시합니다.

### 바뀐 점
- 짧은 확인 기준을 7초로 통일했습니다. 이전에 저장된 통계는 그대로 두므로 업데이트 이후 짧은 확인 수가 줄어 보일 수 있습니다.
- 위젯의 지수 방어선은 하루 마지막 점수로 판정하므로 낮에는 "미달" 대신 숫자와 색으로만 표시합니다.
- 시간대 규칙은 기본 화면 신호등 시간보다 늦게 켜지지 않습니다.
