## DigitsCore v0.9.47

앱 등급을 모두 같은 기준으로 맞추고, 등급이 맞지 않으면 변경을 요청할 수 있게 했습니다. 측정이 멈추면 자동으로 다시 시작합니다. 점수 계산식은 v0.9.46과 같습니다.

- **앱 등급을 모두 같은 기준으로**: 이제 앱 등급은 모든 사용자에게 같은 기본 등급으로 계산합니다. 그래야 코어 지수를 서로 같은 기준으로 볼 수 있습니다. 직접 바꿔 둔 등급은 업데이트한 때부터 기본 등급으로 계산되고, 지난 기록은 그대로입니다.
- **등급 변경 요청**: 등급이 맞지 않는 앱은 앱 등급 화면이나 앱 상세에서 등급을 눌러 변경을 요청할 수 있습니다. 메일 앱이 열리고, 내용을 확인한 뒤 직접 보냅니다. 앱 이름과 등급만 들어가고 사용 시간·점수는 들어가지 않습니다. 검토한 요청은 다음 업데이트의 기본 등급에 반영합니다.
- **인기 앱 기본 등급**: 넷플릭스·티빙·웨이브·디즈니+·왓챠 같은 동영상 앱을 기본 '관리'로 지정했습니다. 빠져 있던 SNS·웹툰·쇼핑 앱도 넣었고, 안드로이드 오토는 '필수'로 넣었습니다.
- **측정 자동 재시작**: 시스템이 측정을 멈추면 묻지 않고 다시 시작합니다. 15분마다 확인하고, 앱을 열 때도 바로 다시 시작합니다. 사용 정보 접근이 꺼진 경우만 직접 켜야 하므로 홈 화면과 알림으로 알려 줍니다.
- **1칸 위젯**: 도룡뇽 아이콘과 점수를 함께 보여 줍니다.
- **심야 사용 시간**: 하루 시작을 05:00로 바꾼 뒤 아침 5~10시 사용이 '심야'로 잡히던 문제를 고쳤습니다. 이제 00:00~05:00만 심야입니다. 이전에 저장된 날의 심야 값은 바뀌지 않습니다.
- **앱 등급 화면의 사용 시간**: 홈 화면과 같은 최근 24시간 기록을 보여 줍니다. 백업을 복원한 날 두 화면 숫자가 다르던 문제를 고쳤습니다.
- 기록 저장소를 열 수 없을 때 측정 서비스가 반복해서 꺼졌다 켜지던 문제를 막았습니다.
- 지난주 기록이 없는 월요일에 주간 리포트를 계속 다시 계산하던 문제를 고쳤습니다.

## DigitsCore v0.9.47

App grades are now the same for everyone, and you can request a change if one looks wrong. Tracking restarts on its own when it stops. Scoring is the same as v0.9.46.

- **Same app grades for everyone**: app grades are now calculated with the same defaults for every user, so Core Index values share one standard. Grades you changed are counted with the default grade from this update on. Past records stay as they are.
- **Grade change requests**: if an app's grade looks wrong, tap its grade on the app grade screen or in app details to request a change. Your mail app opens and you send it yourself after checking it. Only the app name and grades are included, never usage time or scores. Reviewed requests go into the defaults in a later update.
- **Default grades for popular apps**: video streaming apps such as Netflix, Disney+ and Prime Video are now Managed by default. More social, webtoon and shopping apps were added, and Android Auto is now Essential.
- **Automatic restart**: if the system stops tracking, it restarts on its own. It is checked every 15 minutes and again whenever you open the app. Only when usage access is turned off, which you have to fix yourself, the home screen and a notification tell you.
- **1x1 widget** now shows the salamander icon with your score.
- **Late-night usage**: since the day starts at 05:00, usage from 5 to 10 AM was counted as late night. Only 00:00 to 05:00 counts now. Values already saved for earlier days are not changed.
- **Usage on the app grade screen** now uses the same last-24-hours record as the home screen, so the two no longer differ after a backup restore.
- Prevented the tracker from restarting over and over when the record store cannot be opened.
- Fixed the weekly report being recalculated repeatedly on Mondays with no data from the previous week.
