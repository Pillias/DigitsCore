## DigitsCore v0.9.38

v0.9.37의 화면을 더 읽기 쉽게 다듬었습니다. 점수 계산은 바뀌지 않았습니다.

- **요약 3칸**: 큰 글자로 실제 사용량(앱 사용 min · 잠금 해제 x · 쉼 min)을 먼저 보여 주고, 바로 아래에 그만큼이 지수에 준 효과("지수 -6P")를 보여 줍니다.
- **앱별 사용 시간**: 한 앱을 한 줄에 이름 · 사용 시간 · 지수 효과 순서로 보여 줍니다. 이름이 길어도 시간과 지수 효과는 잘리지 않습니다.
- **오늘의 목표 설정**: '평일·주말 따로' 스위치를 켜고 꺼도 아래 내용이 움직이지 않습니다.

---

Polishes the v0.9.37 screens. Scoring is unchanged.

- **Summary tiles** show the actual amount first (app use min · unlocks x · rest min) with its effect on the index below ("Index -6P").
- **App usage** lists one app per line: name · time · index effect. Long names no longer cut off the time or effect.
- **Today's goals**: turning "Separate weekday / weekend" on or off no longer shifts the dialog.
