## DigitsCore v1.0.3

더 적게 읽고, 덜 확인하도록 다듬었습니다. 점수 계산은 그대로입니다.

- **백업 복원은 바로**: 방식을 고르는 단계 없이, 파일과 비밀번호만 넣으면 이 기기 기록이 백업 기록으로 바뀝니다.
- **목표는 알아서**: 오늘의 목표를 매일 자동으로 정합니다. 직접 고르는 화면과 아침 브리핑 팝업은 뺐습니다.
- **짧아진 설명**: 설정과 대시보드의 긴 설명을 줄이고, 자세한 이유는 ? 버튼으로 옮겼습니다. 업데이트 팝업도 띄우지 않습니다(설정의 업데이트 기록에서 볼 수 있습니다).
- **수정**: 권한을 준 뒤 앱을 다시 열면 첫 화면으로 돌아가던 문제, 통계 하이라이트 시간에 날짜가 빠지던 문제, 요일별 화면의 평균·변화 표시를 고쳤습니다.

**의견 보내기**: 설정 → 버그 리포트 또는 DigitsCore@gmail.com

## DigitsCore v1.0.3

Less to read, fewer things to confirm. Scoring is unchanged.

- **One-step restore**: pick the file, enter the password, and this device's history is replaced by the backup. No mode to choose.
- **Goals set for you**: daily goals are picked automatically. The goal picker and the morning briefing popup are gone.
- **Shorter text**: long explanations in Settings and the dashboard are trimmed, with details behind ? buttons. The update popup no longer appears (see Update history in Settings).
- **Fixes**: reopening the app after granting permission no longer returns to the first screen; statistics highlights show the date; the weekday view shows the right average and no misleading change badge.

**Feedback**: Settings → Bug Report or DigitsCore@gmail.com
