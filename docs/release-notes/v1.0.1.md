## DigitsCore v1.0.1

정식 버전의 첫 수정판입니다. 점수 계산은 그대로입니다.

- **더 간단한 첫 화면**: 처음 열면 로고와 이름만 보입니다. 시작하기를 누르면 꼭 필요한 권한 두 가지(사용 정보 접근, 알림)만 묻습니다.
- **백업 복원 후 점수 표시**: 추적을 꺼 둔 기기의 백업을 복원하면 이 기기 추적까지 꺼져 점수가 75에 멈춰 보이던 문제를 고쳤습니다. 이제 추적 설정은 이 기기 값을 유지하고, 복원한 지수가 바로 보입니다.
- **추적 상태 표시**: 추적이 꺼져 있으면 '실시간 추적 진행 중' 대신 '추적이 꺼져 있습니다'라고 알려 줍니다.
- **배터리 예외 안내**: 첫 화면에서 빼고 설정 → 일반으로 옮겼습니다. 예외로 등록하지 않았을 때만 보입니다.

**의견 보내기**: 설정 → 버그 리포트 또는 DigitsCore@gmail.com

## DigitsCore v1.0.1

The first fix-up of the stable release. Scoring is unchanged.

- **Simpler first screen**: the app opens with just the logo and name. Tap Get started and it asks only for the two permissions it needs (usage access and notifications).
- **Score after restoring a backup**: restoring a backup made while tracking was off also turned tracking off on this device, so the score looked stuck at 75. Tracking now keeps this device's setting, and the restored index shows right away.
- **Tracking status**: when tracking is off, the dashboard says so instead of "Live tracking active".
- **Battery exemption tip**: moved from the first screen to Settings → General, shown only when the app is not yet exempt.

**Feedback**: Settings → Bug Report or DigitsCore@gmail.com
