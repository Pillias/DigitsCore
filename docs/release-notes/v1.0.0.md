## DigitsCore v1.0.0 — 정식 출시

공개 테스트를 마치고 정식 버전으로 출시합니다. 앱 기능과 점수 계산은 v0.9.47과 같습니다.

DigitsCore는 스마트폰 사용과 휴식의 균형을 1~99점 **코어 지수** 하나로 보여 줍니다. 앱을 잠그거나 사용을 제한하는 강제 기능은 없습니다. 지금 내 상태를 보고 스스로 조절하도록 돕습니다.

- **코어 지수**: 최근 24시간의 사용과 휴식으로 계산합니다. 관리할 앱을 오래 이어 쓰면 내려가고, 화면을 끄고 쉬면 다시 올라갑니다. 점수가 움직인 이유와 쉬면 언제 회복되는지도 알려 줍니다.
- **정확한 측정**: 화면이 켜지고 잠금이 풀린 동안 앞에 보이는 앱만 셉니다. 측정이 멈추면 자동으로 다시 시작합니다.
- **같은 기준의 앱 등급**: 모든 사용자가 같은 기본 등급으로 계산합니다. 등급이 맞지 않으면 등급을 눌러 변경을 요청할 수 있습니다.
- **오늘의 목표 3개**: 지수 방어선, 관리 앱 시간, 잠금 해제 횟수.
- **연속 기록과 도룡뇽**: 목표를 지킨 날이 이어지면 도룡뇽이 자랍니다. 보호권이 있으면 놓친 하루에도 기록이 이어집니다.
- **통계와 공유**: 시간별·일별·요일별 차트와 앱별 추세. 오늘의 지수를 카드 한 장으로 나눌 수 있습니다(앱 이름·사용 시간은 담기지 않습니다).
- **어디서나 확인**: 상태바 지수, 크기를 바꾸면 내용이 달라지는 홈 화면 위젯, 밝은·어두운 테마, 한국어·영어.
- **기록은 기기 안에만**: 인터넷 권한도, 계정도 없습니다. 사용 기록은 암호화해 저장하고, 비밀번호를 건 백업 파일로 새 폰에 옮길 수 있습니다.

공개 테스트에 참여해 주신 분들께 감사드립니다. 점수 기준은 앞으로도 의견을 받아 다듬겠습니다.

**의견 보내기**: 설정 → 버그 리포트 또는 DigitsCore@gmail.com

## DigitsCore v1.0.0 — First stable release

Open testing is over and this is the first stable release. Features and scoring are the same as v0.9.47.

DigitsCore shows the balance between phone use and rest as one number, the **Core Index** (1–99). There are no forced locks or usage limits. It shows where you are so you can adjust on your own.

- **Core Index**: based on the last 24 hours of use and rest. It drops during long stretches in apps you want to manage and rises again when the screen is off. It tells you why it moved and when a rest will bring it back.
- **Accurate measurement**: only the app on screen while the phone is on and unlocked counts. Tracking restarts on its own if it stops.
- **Same app grades for everyone**: every user shares the same default grades. If one looks wrong, tap it to request a change.
- **Three daily goals**: an index floor, managed app time and unlocks.
- **Streaks and the salamander**: your salamander grows as goal days add up. A shield keeps the streak alive on a missed day.
- **Statistics and sharing**: hourly, daily and weekday charts plus per-app trends. Share today's index as one card (no app names or usage time).
- **Always in view**: index in the status bar, one home-screen widget that changes with its size, light and dark themes, English and Korean.
- **Your data stays on the device**: no internet permission, no account. Usage history is stored encrypted, and a password-protected backup file moves it to a new phone.

Thank you to everyone who joined open testing. Scoring will keep improving with your feedback.

**Feedback**: Settings → Bug Report or DigitsCore@gmail.com
