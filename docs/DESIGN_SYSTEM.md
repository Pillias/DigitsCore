# DigitsCore UI 기준

이 문서는 앱 화면이 기능 추가 과정에서 서로 다른 모양과 동작을 갖지 않도록 하는 디자인 기준입니다.
값은 코드 한 곳에만 두고(아래 "값의 위치"), 화면은 그 값과 공통 부품만 씁니다. 용어는 [GLOSSARY.md](GLOSSARY.md)를 따릅니다.

## 값의 위치

| 종류 | 기준 | 코드 |
|---|---|---|
| 점수 색 | 4단계(80/60/40) × 채우기 / 밝은 배경 글자 / 어두운 배경 글자 | `ui/theme/Color.kt` `ScorePalette` |
| 앱 등급 색 | 권장·필수·일반·관리 4색 | `GradePalette`, `gradeAccentColor()` |
| 차트 계열 색 | 화면 시간(청록 #26A69A)·관리 앱(빨강)·잠금 해제(하늘 #38BDF8) | `ChartScreen`·`ChartManaged`·`ChartUnlock` |
| 테마 색 | 밝은·어두운 테마 모두 같은 역할을 전부 지정 (선택 칩·탭은 파랑 계열) | `ui/theme/Theme.kt` |
| 글자 | 아래 "글자" 절 | `ui/theme/Type.kt` |
| 글자 크기(직접 지정) | 아래 "글자" 절의 크기표 | `ui/theme/Tokens.kt` `DigitsTextSize` |
| 모양 | 막대 2·작은 표시 4·칩 8·칸 12·카드 16·시트 24·다이얼로그 28dp | `ui/theme/Tokens.kt` `DigitsShape`, 테마 `DigitsShapes` |
| 간격 | 4의 배수: 4·8·12·16·20·24dp | — |

위젯·상태바 아이콘·화면 신호등도 `ScorePalette`를 씁니다. 점수 색을 새로 정의하지 않습니다.

## 화면 구조

- 화면 배경은 옅은 중립색, 정보 카드는 단색 표면을 씁니다. 카드 안의 작은 칸은 `colorScheme.tile`을 씁니다(두 테마 모두 카드와 구분됨).
- 기본 좌우 여백 20dp, 카드 내부 여백 14~20dp, 목록 간격 10~20dp.
- 앱 본문은 최대 760dp 폭으로 가운데 정렬합니다.
- 섹션은 제목과 한 줄 설명을 함께 표시합니다. 섹션 전체에 영향을 주는 동작만 오른쪽에 둡니다.
- 대시보드 상단 동작 4개(통계·목표·앱·설정)는 아이콘 아래에 이름을 붙입니다(`LabeledTopAction`).

## 정보 계층

1. 현재 코어 지수와 현재 상태
2. 화면 시간·잠금 해제·관리 앱 시간 요약
3. 앱별 사용 기록
4. 장기 추세와 기준 비교
5. 개인화·표시·데이터 설정

큰 숫자는 결과를, 바로 아래의 짧은 문장은 해석을, 상세 화면은 계산 근거와 기간을 설명합니다.

## 코어 지수 시각 언어

- 앱 메인, 위젯, 런처와 상태바는 모두 전원 버튼형 코어 링을 기본 식별 요소로 씁니다.
- 점수 비율형 링은 빨간 전체 원호 위에 점수만큼 녹색 원호가 진행합니다.
- 중앙 전원 막대와 점수는 빨강·주황·노랑·초록 네 구간(80/60/40)을 따릅니다. 점수 등급 글자(S~F, "지수 단계")는 별도입니다.
- 숫자, 지수 단계와 상태 문장을 항상 함께 보여 색상만으로 판단하지 않게 합니다.

## 아이콘과 기호

- 아이콘은 Material **Rounded** 한 가지 스타일만 씁니다 (`Icons.Rounded.*`, `Icons.AutoMirrored.Rounded.*`).
- 한 아이콘은 한 가지 뜻으로만 씁니다: 통계 TrendingUp, 목표 Flag, 앱 Apps, 설정 Tune, 화면 시간 PhoneAndroid, 잠금 해제 LockOpen, 관리 앱 시간 HourglassBottom.
- "더 보기"는 `MoreLink`(글자 + 꺾쇠), 행 끝의 상세 진입은 `DetailChevron` 하나로 표시합니다.
- 목표 달성·초과는 `GoalStatusMark`(Check / PriorityHigh 아이콘)로 표시합니다.
- 화면 안에서는 ✓ ▲ ▼ ▸ ● ↑ ↓ ↻ ▾ ✕ 같은 기호 글자를 쓰지 않습니다. 알림 문구와 화면 신호등 라벨처럼 아이콘을 넣을 수 없는 곳만 ✓ → ●를 허용합니다.
- 색 이모지는 쓰지 않습니다.
- 누르는 아이콘에는 접근성 설명을 넣고, 글자 옆 장식 아이콘은 설명을 비웁니다(`null`).
- 런처 아이콘은 적응형 아이콘에 단색 레이어(`monochrome`)를 포함해 Android 13+ 테마 아이콘을 지원합니다.

## 글자

- 글꼴: 기기 기본 글꼴. 별도 글꼴을 넣지 않습니다.
- 굵기: Regular·Medium·Bold 세 가지만.
- 숫자: 고정폭 숫자(`tnum`)를 테마 전체에 적용합니다.
- 한글 글자 간격 0.
- 단위 "min"은 숫자 대비 0.7배(0.7em)로 작게 표시합니다(`formatMinutesSmallUnit`).
- 숫자와 단위는 자르지 않습니다. 공간이 부족하면 이름·설명이 먼저 줄어들거나 줄바꿈되고, 요약 줄은 `FlowRow`로 다음 줄로 넘깁니다. 말줄임(…)은 앱 이름처럼 길이가 정해지지 않은 텍스트에만 씁니다.
- 글자 크기 설정 130%에서 잘림이 없어야 합니다.

| 역할 | 테마 스타일 | 크기 / 굵기 |
|---|---|---|
| 점수 | displaySmall | 36sp Bold |
| 화면 제목 | headlineSmall · titleLarge | 24 · 22sp Bold |
| 카드 제목 | titleMedium · titleSmall | 16 · 14sp Bold |
| 본문 | bodyLarge · bodyMedium | 16 · 14sp Regular |
| 보조 | bodySmall · labelMedium · labelSmall | 12 · 12 · 11sp |

테마 스타일로 표현하기 어려운 곳(카드 안 칸, 차트 글자)은 `DigitsTextSize`만 씁니다. 화면 코드에 `fontSize = 13.sp`, `textSize = 11.sp.toPx()`, `RoundedCornerShape(12.dp)`처럼 숫자를 직접 쓰지 않습니다.

| DigitsTextSize | sp | 쓰임 |
|---|---|---|
| chart | 8.5 | 대시보드 24시간 차트 안 숫자 |
| micro | 9 | 차트 축·날짜 |
| tiny | 10 | 작은 배지 |
| caption | 11 | 보조 설명·범례 |
| label | 12 | 라벨·작은 본문 |
| body | 13 | 카드 안 본문 |
| bodyLarge · emphasis | 14 · 15 | 강조 본문 · 행 제목 |
| title · titleLarge | 16 · 18 | 카드 제목 · 요약 수치 |
| headline · headlineLarge | 20 · 22 | 화면 안 큰 수치 |
| display · displayLarge · hero · heroLarge | 26 · 28 · 32 · 34 | 점수 링·큰 점수 |

## 색상과 접근성

- 밝은 테마의 주요 액션은 짙은 파랑(#1769AA)을 씁니다.
- 점수 색(빨강·주황·노랑·초록)은 점수 상태와 그래프에만 씁니다. 글자로 쓸 때는 `scoreTextColor()`·`Score*Text`(흰 배경 대비 4.5:1 이상)를 씁니다. 채우기 색(#2ECC71 등)을 글자에 쓰지 않습니다.
- 그래프의 날짜와 점수 글자는 `outline` 및 `onSurface` 색을 씁니다. 차트의 최고·최저 라벨은 실제 글자 폭을 재서 차트 안에 둡니다.

## 상호작용

- 대시보드의 최근 24시간 코어 지수, 요약 지표와 앱 행은 모두 눌러 상세 내용을 볼 수 있습니다.
- 앱 등급 목록의 각 행은 등급 설명과 변경 옵션을 엽니다.
- 카드 전체를 터치 대상으로 써서 작은 글자나 아이콘만 정확히 누를 필요가 없게 합니다.

## 다국어

- 새 문구는 `strings.xml`(한국어·영어)에 추가합니다. `UiTranslator`의 문장 치환 목록은 화면 단위로 strings.xml로 옮기며 줄여 갑니다.
- `UiTranslator`의 일반 단위 치환은 뜻을 단정하지 않습니다: "회" → times, "개" → 숫자만, "목표" → goal.
- 영어 모드 회귀 테스트(`UiTranslatorTest`)에 새 동적 문장을 추가해 한글 잔류를 막습니다.

## 화면별 점검표

| 화면 | 주요 상세 진입 | 직접 조작 |
|---|---|---|
| 온보딩 | 개인정보 카드 | 권한 카드, 시작 버튼 |
| 대시보드 | 코어 지수, 3개 요약, 오늘의 목표(각 칸 → 목표별 상세, ? → 안내), 앱별 행 | 통계·목표·앱·설정 이동, 활성 시간대 규칙 배지 |
| 통계 | 시간별(30일) 선, 일별(4주) 캔들, 요일별, 앱 순위(잠금 후 첫 앱, 알림 잠금 포함) | 좌우 이동·확대·시점 선택, 날짜/앱 상세 진입, 불러온 기록 표시 |
| 앱 등급 | 모든 앱 행 | 검색, 정렬, 권장·필수·일반·관리 4단계 등급 저장 |
| 설정 | 일반·점수·알림·데이터 탭 | 언어, 점수 모드, 표시, 추적, 주간 리포트·시간대 규칙(최대 3개), 지난 기록 불러오기, 백업·복원·삭제 |
| 주간 리포트 | 지난주 마감 점수·목표 달성·시간·잠금·앱 변화 5개 카드 | 다이얼로그 닫기, 상세 통계 화면 바로가기 |

## 알림 채널 체계

| 채널 ID | 이름 | 중요도 | 용도 |
|---|---|---|---|
| `digitscore_status_channel` | 실시간 코어 지수 | LOW | 상시 상태바 아이콘 및 코어 지수 알림 |
| `digitscore_guidance_channel` | 코어 지수 안내 | DEFAULT | 점수 급락 또는 30분 연속 사용 안내 |
| `digitscore_soft_guidance_v2` | 부드러운 사용 경고 | LOW | 소리·진동 없는 알림창 전용 경고 |
| `digitscore_wake_prompt_channel` | 기상 확인 | HIGH | 아침 기상 감지 시 헤드업 브리핑 안내 |
| `digitscore_goal_channel` | 오늘의 목표 | DEFAULT | 목표 한도 도달 알림 및 선택 카드 |
| `digitscore_weekly_report` | 주간 리포트 | DEFAULT | 매주 월요일 05:00 이후 지난주 결산 안내 |

## 검수

- `scripts/design_check.sh`: 테마 폴더 밖의 직접 지정 색·글자 크기·모서리, 쓰지 않는 용어, 화면 안 기호 글자를 셉니다. 글자 크기와 모서리 직접 지정은 0이어야 합니다(`STRICT=1`이면 실패).
- 화면 캡처 점검: 주요 화면 × (밝음·어두움) × (글자 100·130%) × (한국어·영어)를 에뮬레이터 작업 대기열로 찍어 전후를 비교합니다.
