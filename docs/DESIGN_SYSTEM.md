# DigitsCore UI 기준

이 문서는 앱 화면이 기능 추가 과정에서 서로 다른 모양과 동작을 갖지 않도록 하는 최소 디자인 기준입니다.

## 화면 구조

- 화면 배경은 옅은 중립색, 정보 카드는 명확한 단색 표면을 사용합니다.
- 기본 좌우 여백은 20dp, 카드 내부 여백은 14~20dp, 목록 간격은 10~20dp를 사용합니다.
- 일반 카드는 16dp, 주요 점수 카드는 20dp, 다이얼로그는 28dp 모서리를 기본으로 합니다.
- 섹션은 제목과 한 줄 설명을 함께 표시합니다. 섹션 전체에 영향을 주는 동작만 우측 액션으로 둡니다.
- 장식용 이모지는 제목에 사용하지 않습니다. 의미는 Material 아이콘, 색상, 텍스트 계층으로 전달합니다.

## 정보 계층

1. 현재 코어 지수와 현재 상태
2. 화면시간·언락·관리 앱 시간 요약
3. 앱별 사용 기록
4. 장기 추세와 기준 비교
5. 개인화·표시·데이터 설정

큰 숫자는 결과를, 바로 아래의 짧은 문장은 해석을, 상세 화면은 계산 근거와 기간을 설명합니다.

## 상호작용

- 대시보드의 점수, 이전 점수, 요약 지표와 앱 행은 모두 눌러 상세 내용을 볼 수 있습니다.
- 통계의 기간 안내, 기준 비교, 그래프와 요약 지표는 모두 상세 설명을 제공합니다.
- 앱 등급 목록의 각 행은 등급 설명과 변경 옵션을 엽니다.
- 설정값은 카드 안에서 직접 조절하며, 읽기 전용 기준·버전 정보는 누르면 설명을 표시합니다.
- 상세로 이동하는 항목은 우측 꺾쇠를 표시합니다. 단순 상태나 장식 요소에는 표시하지 않습니다.
- 카드 전체를 터치 대상으로 사용해 작은 텍스트나 아이콘만 정확히 누를 필요가 없게 합니다.

## 색상과 접근성

- 밝은 테마의 주요 액션은 흰색 배경에서도 읽을 수 있는 짙은 파랑을 사용합니다.
- 빨강·주황·노랑·초록은 점수 상태와 그래프 범례에만 제한적으로 사용합니다.
- 상태를 색상만으로 전달하지 않고 항상 이름, 점수 또는 설명을 함께 표시합니다.
- 그래프의 날짜와 점수 글자는 현재 테마의 `outline` 및 `onSurface` 색상을 사용합니다.
- 아이콘 버튼과 상세 꺾쇠에는 접근성 설명을 제공합니다.

## 다국어와 작은 화면

- 화면 텍스트는 공통 번역 경로 또는 Android 문자열 리소스를 사용합니다.
- 동적 숫자 문장은 영어 모드 회귀 테스트에 추가하여 한글 잔류를 막습니다.
- 긴 영어 제목은 가변 폭을 사용하고, 고정 폭 텍스트 옆에서는 먼저 줄어들거나 줄바꿈됩니다.
- 목록과 다이얼로그 본문은 스크롤 가능해야 하며, 주요 완료·취소 동작은 본문 밖에 둡니다.

## 화면별 점검표

| 화면 | 주요 상세 진입 | 직접 조작 |
|---|---|---|
| 온보딩 | 개인정보 카드 | 권한 카드, 시작 버튼 |
| 대시보드 | 점수, 이전 점수, 3개 요약, 앱별 행 | 전체 앱, 통계·등급·설정 이동 |
| 통계 | 기록 범위, 기준 비교, 두 그래프, 4개 지표 | 7일·30일 기간 선택 |
| 앱 등급 | 모든 앱 행 | 검색, 5단계 등급 저장 |
| 설정 | 보정 기준, 앱 버전 | 언어, 프리셋, 표시, 추적, 가중치, 백업·복원·삭제 |
