# 20~50명·30일 사용자 검증 계획

## 목표

코어 지수가 일반적인 사용에서 약 70점, 절제된 사용에서 80~90점, 장시간 몰입 관리 앱 사용에서 낮은 점수로 충분히 움직이는지 확인합니다. 타인의 절대 사용시간을 평가하는 연구가 아니라 사용자 자신의 변화가 이해되고 행동으로 이어지는지 검증합니다.

## 운영

- 1차 20명으로 측정 누락·이탈·설명 이해도를 확인한 뒤 최대 50명으로 확대합니다.
- 동일 release 후보를 30일 사용하며 7일 단위 짧은 설문과 종료 인터뷰를 진행합니다.
- 직장인/학생 등 생활 유형은 자가 선택하되 어린이는 보호자 동의와 별도 법률·Families 검토 전 모집하지 않습니다.
- 참여 철회, 앱 내 즉시 삭제, 데이터 사용 목적과 보유기간을 모집 전에 설명합니다.

## 수집 최소화

- 기본 수집값: 익명 참여 코드, 앱 버전, 기기 제조사/OS, 일별 코어 지수(최저/평균/최고), 화면시간 합계, 3단계별 시간 합계, 언락 수, 포착률, 일일 배터리율, Crash/ANR 여부
- 기본 제외값: 앱 이름·패키지, 알림 내용, 정확한 앱 실행 시각, 계정/연락처/Android ID
- 개별 앱 원본이 필요한 오류 분석은 별도 동의를 받은 사례에서만 사용하고 해결 후 삭제합니다.

## 핵심 지표

1. 점수 분포: 전체 및 사용자별 P5/P25/중앙값/P75/P95, 0~39/40~49/50~69/70~89/90~100 비율
2. 변화성: 하루 절대 변화 중앙값, 3점 이상 움직인 날 비율, 같은 점수로 머문 시간
3. 방향성: 몰입 관리 앱 사용 증가일의 점수 하락 비율, 휴식 후 회복 방향 일치율
4. 이해도: 변화 이유를 맞게 설명한 비율, 제안이 실행 가능하다는 5점 척도
5. 제품성: D1/D7/D30 유지, 알림 끄기, 추적 끄기, 버그 리포트 수
6. 신뢰성: Digital Wellbeing 대비 오차, 포착률, 배터리, 서비스 공백

## 사전 판정 기준 초안

- 사용자별 30일 중앙값의 전체 중앙이 65~75
- 전체 관측의 90% 이상이 40~90, 0~39와 90 초과는 각각 드문 꼬리 구간
- 몰입 관리 앱을 3시간 이상 사용한 날의 중앙 지수는 약 40~50
- 몰입 관리 앱 사용이 적은 사용자에서 80점대가 관측되되 성장 앱 사용만으로 급등하지 않음
- 사용자의 80% 이상이 ‘왜 움직였는지’ 설명을 이해
- 3점 이상 일중 변화가 대부분의 활성일에서 관측되지만 짧은 확인 하나로 급락하지 않음

기준을 맞추기 위해 같은 실험 중간에 점수 공식을 바꾸지 않습니다. 공식 변경은 새 버전/코호트로 분리합니다.

## 종료 보고서

모집·완주 인원, 제외 기준, 버전, 점수 분포 그래프, 기기별 정확도/배터리, 정성 피드백, 변경할 계수, 보류할 기능을 기록합니다. 개인별 앱 목록이나 원본 사용 타임라인은 보고서에 넣지 않습니다.
