# 탐색형 사용 통계

## 화면

- **24시간:** 현재 시점 기준 선 그래프. 좌우 이동, 1–4배 확대, 이전/다음 하루 탐색.
- **1주·4주·3개월·1년:** 일별 캔들. 1주·4주에서는 시간봉으로 전환 가능.
- 캔들 몸통은 첫 점수와 마지막 점수, 꼬리는 관측된 최고·최저. 표본 하나뿐이면 점으로 표시.
- 이전 점수 모델은 회색. 다른 모델을 같은 캔들이나 변화량 계산에 섞지 않음.
- 자세한 차트는 같은 시간축에 일반/관리 사용시간과 앱 오픈을 표시. 주황색은 전체 오픈 중 1분 이하 실행이며 별도 합산하지 않음. 오픈 패널은 잠금 해제로 전환 가능.
- 탭/길게 누른 뒤 이동하면 시점별 값 표시. 날짜를 선택해 하루 상세로 이동. 버튼으로도 기간과 기록을 탐색할 수 있음.
- 차트 아래에는 사용시간·점수 영향·오픈 횟수별 상위 3개 앱과 전체 보기. 앱을 누르면 해당 기간의 사용/오픈 추세 및 감점 기록을 표시.

## 감점 기여도

`CumulativeTimeline`이 각 실제 점수 전이의 전후 표시 점수를 전달한다. 오픈 감점은 실제 열린 앱, 사용시간 감점은 PiP·분할 화면의 유효 등급 앱에 한 번만 배정한다. 회복은 앱에 배정하지 않는다.

점수 체크포인트, 시간별 OHLC, 감점·회복 집계를 **동일 Room 트랜잭션**에서 저장한다. 재조회나 프로세스 재시작으로 같은 감점을 더하지 않는다. 반올림 전 표시 점수를 사용하므로 작은 감점도 누적된다.

시간별 감점 기록이 조회 범위 경계에 걸치면 임의 비례 배분하지 않는다. 완전히 포함된 기록만 합계에 넣고 기록 시작 시점을 표시한다. 과거 사용시간으로 감점을 역산하지 않는다.

## 보존

| 기록 | 보존 | 용도 |
|---|---|---|
| 앱 시작·종료 세션 | 30일 | 정밀 시간대·연속 사용 |
| 5분 코어 지수 표본 | 30일 | 하루 상세 선 그래프 |
| 최소 잠금 해제·알림 이벤트 | 48시간 | 최근 24시간 경계의 실제 이벤트 집계 |
| 시간별 전체/앱 사용·오픈·짧은 실행 | 365일 | 장기 시간대 및 앱 순위 |
| 시간별 점수 OHLC·실제 감점·회복 | 365일 | 일/시간 캔들 및 기여도 |
| 기존 일별 집계 | 365일 | 장기 기록 호환 |
| 누적 점수 체크포인트 | 전체 삭제 전까지 | 보존 기간과 독립적인 누적 상태 |

원본 삭제 **전에** 시간별 집계를 확정한다. 최초 업그레이드에서는 남아 있는 세션·점수 표본만 시간별로 이관한다. 30일이 지난 날짜의 하루 상세는 시간별 해상도로 표시한다. 이미 없어진 원본, 기여도, 세부 시간대는 생성하지 않는다.

DB v19는 기존 테이블을 유지하면서 네 개의 집계/커서 테이블을 추가한다. 백업 v11은 시간별 집계를 포함하며 기존 백업도 읽는다. 복원 시 동일 시간/앱의 기존 집계를 중복 합산하지 않는다. 모든 사용 기록 삭제는 새 테이블도 포함한다.

## 검증

단위 테스트: 자정·시간 경계, 세션 조각 중복, 1분 이하·진행 중 확인, PiP 중복 방지, 실제 점수 변화와 기여도 합계 일치, 모델 혼합 방지, 미기록 보존.

기기 테스트: v18→19 이전, 중복 조회, 원본 만료 후 집계 유지, 백업 반복 복원, 영어 기간/봉 전환·앱 상세·다크 큰 글꼴 렌더링. 실제 Samsung의 제스처 감도·큰 글꼴·TalkBack은 실사용 확인이 추가로 필요하다.
