# DigitsCore 정식 출시 및 Phase 2 로드맵 (v1.0 ~ v1.3)

- 최종 갱신: 2026-10-28 (2차: v1.0 범위 확대, 익명 비교를 평균 기준값으로 변경, 수집 범위 재검토). 이전 판은 v0.9.10 기준(2026-10-20 커밋 `a36fead`)이었습니다.
- 정식 출시 가능일: **2026-10-31**. 비공개 테스트 기간이 끝나는 날입니다.
- 판단 기준: **코어 지수 하나**. 선택지가 많으면 쓰기 어렵기 때문에 점수를 하나로 정했습니다. 새 기능은 아래 셋 중 하나에 해당해야 합니다.
  - 지수에 더 집중하게 하는가
  - 지수를 올리도록 북돋우는가
  - 지수를 비교해서 보여주는가
  - 위 셋에 해당하지 않으면서 점수 계산 방식이나 설정 선택지를 늘리는 기능은 하지 않습니다.

## 1. v1.0 정식 출시 (2026-10-31)

### 1.1 포함 범위 (2026-10-28 사용자 결정: v1.0.x 항목까지 v1.0에 포함)
- v0.9.37~0.9.39: 코어 지수 단일 단계(안정·보통·주의·휴식 필요), 잠금 해제 페이스 반영(시간당 기준 5회), 요약 3칸(양 먼저 + 지수 효과), 평소 대비, 코치 목표 1시간 이내.
- 보상: 연속 기록 보호권(자유권 대체) · 도룡뇽 성장 단계(7·14·30일, 단계별 그림 4종) · 내 기록(관리 앱 최소 · 잠금 해제 최소 · 최장 연속). (DEBATE 안건 19)
- U-1: 1시간 안에 +1P가 안 되면 소수점(+0.6P) 대신 "화면을 끄면 감점이 바로 멈춰요. 30min 쉬면 지수가 다시 올라요".
- U-2: '가장 긴 쉼'은 오늘(05:00 이후) 기준. 밤잠이 차지하지 않음.
- A-1: 지난 사용 기록을 불러온 뒤 가장 많이 쓴 앱 3개 등급 확인 카드(1회).
- R-3: 단계가 오른 뒤 처음 볼 때 지수 링이 한 번 0부터 차오름.
- `INTERNET` 권한 없음. 완전 오프라인. 버전 `1.0.0` (versionCode 1000).

## 2. Phase 2 재정리

### 2.1 Opt-in 익명 '다른 사용자 평균' (v1.1) — 1순위

**실시간 비교가 아닙니다.** (2026-10-28 사용자 지적 반영)
- 수집: 하루 1회, 전날 하루 요약만 보냅니다(기본 OFF, 켠 사람만).
- 배포: 서버가 모인 자료로 **평균·표준편차 표를 주 1회** 만들어 정적 파일 하나(`benchmark_v1.json`, 수 KB)로 올립니다. 앱은 이 표를 받아 둡니다.
- 표시: 지금 화면 틀은 그대로 두고, 이미 있는 '평소 대비' 자리에 **기준값 하나**를 더합니다.
  - 히어로 카드: "평소 대비 +3P · 다른 사용자 평균 대비 +5P" (같은 분류·같은 시간대 평균과 비교)
  - 통계 차트: 기준선 1개('다른 사용자 평균')를 내 방어선처럼 회색 점선으로.
  - 요약 3칸 상세: "관리 앱 1h 20min · 평균 1h 50min"처럼 숫자 옆 평균 하나.
  - 백분위('상위 X%')와 지표별 순위표는 만들지 않습니다. 표준점수는 화면에 숫자로 내지 않고 '평균보다 많음/비슷/적음' 판정(±0.5σ)에만 씁니다.
- 최소 인원 200명 조건은 두지 않습니다. 대신 **개인 식별 방지용 최소 조건만**: 분류 칸 하나에 서로 다른 참여자 5명 미만이면 그 칸은 표에 넣지 않고 상위 분류(전체 평균)로 대신합니다. 참여자가 적은 초기에는 '전체 평균'만 나옵니다.
- 함께 할 일: `INTERNET` 권한, Data Safety·개인정보처리방침 갱신, 설정에 참여 토글 1개.
- 내부 활용: 실데이터 평균·분포로 엔진 기본 계수(잠금 해제 기준 12min 포함)를 다시 맞춤. 사용자 설정은 늘리지 않음.

### 2.1.1 익명 수집 범위 재검토 (평균·표준점수를 나누기 위한 분류 기준 포함)

원칙: 앱 이름·개인정보는 빼고, **평균을 공정하게 나누는 데 꼭 필요한 기준만 거칠게(구간으로)** 받습니다. 분류 기준은 '비교 대상이 비슷한 사람인가'를 맞추는 용도이고, 화면에 노출되는 분류는 최대 2개로 제한합니다.

| 구분 | 항목 | 형태 | 왜 필요한가 |
| :--- | :--- | :--- | :--- |
| 지표 | 하루 마지막·평균·최고·최저 코어 지수 | 정수 | 평균 비교의 본체 |
| 지표 | 시간대별 지수 24칸 | 정수 24개 | '같은 시간대' 평균 기준선 |
| 지표 | 관리 앱 시간, 전체 화면 시간 | 분(10분 단위 반올림) | 요약 칸 평균 |
| 지표 | 잠금 해제 수, 잠금 해제 지수 효과 합 | 정수 | 요약 칸 평균, 페이스 기준 보정 |
| 지표 | 오늘 가장 긴 쉼 | 분(10분 단위) | 쉼 평균 |
| 지표 | 목표 사용 여부·달성 수(0~3), 연속 일수 구간 | 정수·구간 | 목표·보상이 지수를 올리는지 확인(내부) |
| **분류(화면 노출)** | 요일 유형 | 평일/주말 | 주말 사용량이 크게 달라 평균을 나눠야 함 |
| **분류(화면 노출, 선택 입력)** | 생활 유형 | 학생/직장인/자영업·프리랜서/기타/응답 안 함 | 같은 처지 사람과 비교해야 동기 부여가 됨 |
| 분류(보정용, 비노출) | 연령대 (선택 입력) | 14~19/20대/30대/40대/50대+/응답 안 함 | 연령별 차이 확인. 14세 미만은 받지 않음 |
| 분류(보정용, 비노출) | 기상·취침 시각 | 30분 구간 | 생활 리듬이 다른 사람끼리 시간대 평균이 섞이지 않게 |
| 분류(보정용, 비노출) | 관리 앱으로 지정한 앱 수 | 구간(0/1~3/4~7/8+) | 관리 앱 시간은 몇 개를 지정했는지에 크게 좌우됨 — 이걸 모르면 평균이 왜곡 |
| 분류(보정용, 비노출) | 사용 기간 | 구간(<7일/7~30일/30일+) | 처음 쓰는 주는 등급 정리가 덜 돼 값이 흔들림 |
| 품질 | 측정 비율(서비스 가동 %), 지난 기록 불러오기 날 여부 | 정수·참거짓 | 측정이 빠진 날·불러온 날은 평균에서 제외 |
| 품질 | 제조사 구간, Android 주 버전, 점수 모델 버전(6), 앱 버전 | 구간·정수 | 제조사별 잠금 해제 이벤트 차이, 모델 바뀐 자료 섞임 방지 |
| 메타 | 참여 ID | 기기에서 만든 무작위 값, 30일마다 교체 | 같은 사람 하루 중복 방지, '사람 수' 기준 5명 조건 계산 |
| 메타 | 날짜 | 날짜만(시각 없음), 시간대 오프셋 | 하루 단위 집계 |

**받지 않는 것**: 앱 이름·패키지, 앱별 시간, 시각 단위 사용 기록, 위치, 기기 모델명, 이메일·전화·계정·광고 ID, 정확한 나이·성별.

**정리**
- 화면에 쓰는 분류는 '요일 유형 × 생활 유형' 2개뿐 (최대 10칸). 칸이 5명 미만이면 생활 유형을 빼고 요일 유형만, 그래도 부족하면 전체 평균.
- 연령대·기상 시각·관리 앱 수·사용 기간은 화면 분류로 쓰지 않고 **평균을 보정**(예: 관리 앱 수 구간별 차이를 빼고 평균 계산)하거나 계수 튜닝에만 씁니다. 선택지를 늘리지 않기 위함.
- 생활 유형·연령대는 참여 토글을 켤 때 한 화면에서 한 번만 묻고, '응답 안 함'이 기본입니다. 연령대·생활 유형은 Data Safety에서 '개인 정보(선택)'로 신고 대상.
- 표준점수(z)는 서버 표의 평균·표준편차로 기기에서 계산하고, 화면에는 'P 차이'와 '많음/비슷/적음'만 보여 줍니다.

### 2.2 DigitsCore Pro · 1회 결제 (v1.2)
- **원칙**: 지수를 올리는 데 필요한 기능은 모두 무료입니다. 보호권·도룡뇽·내 기록·코치도 무료입니다. Pro는 '더 오래, 함께 보기'입니다.
- **구성안**
  1. **365일 기록 · 연간 잔디 캘린더**
     - 칸 색 = 그날 단계
     - 도룡뇽 단계 변화 표시
     - 3·6·12개월 추세
     - 데이터는 이미 365일 보관하고 있습니다.
  2. **내 기록 확장**
     - 월별 최저 관리 앱 / 최저 잠금 해제
     - 기록 갱신 히스토리
  3. **위젯 팩**
     - 도룡뇽 단계 위젯
     - 잔디 위젯
  4. **친구·가족 방 개설(호스트)**: v1.3 출시 시 자동 포함
- **결제**
  - Google Play Billing, 비소모성 1회 상품
  - 가격대는 사용자가 결정합니다(예: ₩5,900~9,900).
- **하지 않음**: 전문 프리셋, 수식 가중치 조정, 시간대 자동 등급 스케줄러, 설정 PIN

### 2.3 친구·가족 비교 보드 (v1.3)
- **참여 방식**: 계정 없이 6자리 방 코드와 별명으로 참여합니다.
  - 방 개설은 Pro, 참여는 무료입니다.
  - 최대 6명입니다.
- **공유 항목은 4개뿐**
  - 현재 지수
  - 단계
  - 연속 일수
  - 도룡뇽 단계
- **공유하지 않는 것**: 화면시간, 잠금 해제 수, 앱 목록
- **보드 화면**
  - 지수 순 정렬
  - 각자의 도룡뇽
  - '오늘 방어선 지킨 사람' 표시
- **보드에 넣지 않는 것**: 응원 버튼, 채팅. 보드는 비교에만 씁니다.
