DigitsCore 개인정보처리방침

최종 수정일 및 시행일: 2026년 10월 3일
핵심 요약: DigitsCore는 사용자의 사용 기록을 외부 서버로 전송하지 않습니다. 광고 SDK나 서드파티 분석 SDK가 없으며, 모든 데이터는 SQLCipher와 Android Keystore를 통해 기기 내부에서 암호화되어 로컬에서만 처리됩니다.

1. 처리하는 정보

DigitsCore는 사용자가 Android의 사용 정보 접근 권한을 직접 허용한 경우 다음 정보를 기기 내부에서 읽어 처리합니다.

  • 앱 이름 및 패키지 이름
  • 화면 ON·잠금 해제 상태에서 마지막으로 상호작용한 앱의 사용 구간·전환 시각과 분할 화면·PiP에서 함께 표시된 앱 중 점수 부하가 가장 높은 앱/등급 (30일 보관)
  • 앱별 일일 사용시간·실행 횟수·1분 미만 실행 횟수 집계 (365일 보관)
  • 화면이 켜진 동안 계산한 5분 단위 코어 지수 변화 표본 (30일 보관)
  • 시간별 전체/앱 사용시간·오픈 횟수·1분 이하 실행, 점수 시작·마지막·최저·최고, 실제 감점 및 회복 집계 (365일 보관)
  • 기기 잠금 해제 이벤트 (ACTION_USER_PRESENT, KEYGUARD_HIDDEN) 시각 및 횟수 (48시간 보관)
  • Android UsageEvents가 제공하는 알림 interruption 수치
  • 사용자가 앱에서 지정한 분류, 점수 규칙, 언어·화면 모드·알림·위젯 설정
  • 홈 위젯 재생성을 위한 마지막 코어 지수·화면시간·관리 앱 시간·언락 횟수·상태 요약

2. 처리 목적

위 정보는 24시간 누적 코어 지수 계산, 분할 화면·PiP를 포함한 앱 사용 부담 산출, 앱별 시간대·세션·짧은 실행·장기 추세 통계, 잠금 해제 시간대 비교를 계산하여 앱 화면, 상태바 알림, 홈 화면 위젯에 표시하는 목적으로만 사용됩니다.

알림 내용은 일체 읽거나 저장하지 않으며 Android UsageEvents가 제공하는 통계 이벤트 수치만 비교에 사용합니다.

3. 저장, 전송 및 제3자 제공 (서버 전송 없음)

  • 기기 내 로컬 암호화: 사용 기록과 설정은 기기 내부 데이터베이스에 저장되며, SQLCipher 및 Android Keystore 암호화 키로 강력하게 보호됩니다.
  • 클라우드 백업 제외: 데이터베이스, 설정 및 암호화 키 파일은 OS 자동 클라우드 백업 및 기기 간 자동 전송 대상에서 명시적으로 제외됩니다.
  • 서버 전송 및 판매 없음: DigitsCore는 사용 기록을 개발자 서버로 전송하지 않으며, 제3자에게 수집·판매하지 않습니다.
  • 광고 및 트래커 부재: 광고 SDK와 외부 분석(Analytics) SDK를 일체 탑재하지 않습니다.
  • 사용자 직접 백업: 사용자가 수동 백업 기능을 직접 실행한 경우에만, 사용자 비밀번호로 AES-256-GCM 암호화된 백업 파일이 Android 공유 시트로 생성됩니다.
  • 버그 리포트 직접 전달: 사용자가 버그 리포트 기능을 직접 실행할 경우 진단 정보와 함께 최대 5장의 화면 캡처를 선택 첨부하여 지원 이메일(DigitsCore@gmail.com)로 보낼 수 있으며, 개인 식별자나 앱 목록은 자동 수집되지 않습니다.

4. 보유 및 삭제

앱별 상세 사용 구간과 5분 단위 코어 지수 표본은 30일, 잠금 해제 이벤트는 48시간, 시간별·일별 통계 집계는 365일간 기기 내부에 보관된 후 자동 삭제됩니다.

사용자는 앱 설정의 [모든 사용 기록 즉시 삭제]를 누르거나, Android 앱 설정에서 데이터를 삭제하거나 앱을 제거하여 언제든지 모든 저장 정보를 즉시 영구 삭제할 수 있습니다.

Executive Summary: DigitsCore does NOT transmit your usage data to any external server. All app usage data, unlock counts, and Core Index scores are processed and stored locally on your device with SQLCipher and Android Keystore encryption. No ads, no analytics SDKs.

1. Information Processed (On-Device Only)

  • Foreground application name and package name
  • Screen-on time, app usage intervals, and app switch timestamps (stored locally up to 30 days)
  • Daily app usage statistics and launch frequencies (stored locally up to 365 days)
  • Device unlock timestamps (via ACTION_USER_PRESENT, KEYGUARD_HIDDEN, stored up to 48 hours)
  • User-configured score preferences, themes, and notification presets

2. Purpose of Processing

Data is used exclusively to compute your real-time 24-hour Core Index score, screen time analytics, and display them on the in-app dashboard, status bar notification, and home widgets.

3. Storage, Transmission & Sharing (Zero Server Transmission)

  • On-Device Encryption: Database is encrypted using SQLCipher and protected with Android Keystore.
  • No External Transmission: DigitsCore does not operate a collection server and does not transmit, sell, or share personal data with any third party.
  • No Ad or Analytics SDKs: The application contains zero advertising SDKs and zero third-party tracking libraries.
  • User-Initiated Bug Reports: When submitting bug reports, users can optionally attach up to 5 screenshots directly via email (DigitsCore@gmail.com). No personal device identifiers or app lists are automatically collected.

4. Data Retention and Deletion

Users can delete all stored data immediately at any time by selecting "Delete All Records Immediately" within the app settings, or by clearing app storage / uninstalling the app in Android system settings.
