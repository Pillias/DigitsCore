# DigitsCore 출시 준비 현황

기준일: 2026-09-14 · 앱과 문서의 상태 정의는 `ReleaseReadiness.kt`를 기준으로 맞춥니다.

상태는 네 가지입니다.

- **완료**: 코드와 자동 검증이 준비됨
- **검증 준비**: 측정/제출 도구는 준비됐고 실기기 결과가 필요함
- **관리자 입력**: 저장소에 넣을 수 없는 소유자 정보나 비밀키가 필요함
- **외부 검증**: 실제 기기, Play Console 또는 참여자가 필요함

현재 요약: **완료 8/16 · 검증 준비 3/16 · 관리자 입력 2/16 · 외부 검증 3/16**

## 검증 자료 보관 규칙

- 원본 스크린샷·CSV·영상에는 참여자의 앱 이름이나 알림 내용이 보이지 않게 합니다.
- 저장소에는 개인별 원본이 아니라 제조사/버전별 집계 결과와 이슈 번호만 커밋합니다.
- 한 항목을 완료로 바꿀 때 결과 파일 또는 Play Console 화면의 보관 위치와 확인 날짜를 표에 추가합니다.
