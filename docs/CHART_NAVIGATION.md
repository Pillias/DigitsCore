# Chart navigation

- Hourly · 24H keeps the moving 24-hour index and hourly usage overlay.
- Daily · 4W displays daily open/close/low/high values and the same-model seven-day closing-index average. Swipe horizontally through dates; tap a candle to open intraday detail. Previous/next buttons navigate recorded days without closing the detail.
- Weekly · 4W groups available days by Monday-based calendar weeks. Each point is a daily closing index, on the same fixed 0–100 scale. The first/last values describe the available records, not a weekly average. Missing days and model/preset changes break the line.
- The trailing 28 days may intersect five calendar weeks. Edge weeks are partial; their headings show full calendar-week boundaries and date buttons show which records are available.
- These controls change presentation only; they do not change the rolling scoring model or retention.

Device acceptance: verify horizontal chart swiping does not open a day until tapped, previous/next navigation stays within recorded dates, and settings dropdown values follow Korean/English selection. Intraday detail requires retained samples; older aggregate-only days explicitly show no intraday records.
